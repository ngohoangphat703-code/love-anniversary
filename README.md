# 💖 Góc Kỷ Niệm Tình Yêu - Phát & Nhung

Trang web kỷ niệm tình yêu dành riêng cho **Phát & Nhung**, được thiết kế với giao diện Glassmorphism hiện đại, tích hợp đếm thời gian bên nhau, phát nhạc tình yêu trực tuyến, album lưu giữ khoảnh khắc và thông điệp yêu thương.

## ✨ Tính Năng Nổi Bật

1. **Đăng nhập bảo mật góc nhỏ**: Giúp giữ riêng tư cho hai người (`PhatxNhung` / `PhatxNhung`).
2. **Bộ đếm thời gian thực (Love Counter)**: Tính chính xác từng giây, phút, giờ, ngày hai bạn đã bên nhau.
3. **Music Player thông minh**:
   - Tích hợp nhạc gợi ý chất lượng cao.
   - Tìm kiếm bài hát trực tuyến qua iTunes API.
   - Hỗ trợ chế độ lặp bài hát liên tục.
4. **Album ảnh kỷ niệm**:
   - Cho phép tải ảnh trực tiếp lên giao diện (tự động nén ảnh tối ưu bộ nhớ LocalStorage).
   - Lightbox phóng to xem ảnh sắc nét.
5. **Thông điệp yêu thương**: Ngẫu nhiên hiển thị lời chúc ngọt ngào hoặc tự viết thêm câu chúc mới.
6. **Hiệu ứng trái tim trôi & Bắn pháo hoa Confetti**.

## 🚀 Hướng Dẫn Chạy Dự Án

### Chạy trực tiếp trên máy tính:
Chỉ cần tải code về và nhấp đúp file `index.html` để mở trên trình duyệt.

### Deploy miễn phí lên GitHub Pages:
1. Tạo một repository mới trên GitHub (ví dụ: `love-anniversary`).
2. Push toàn bộ mã nguồn này lên repository.
3. Vào **Settings** > **Pages** > Chọn Branch `main` (hoặc `master`) > Bấm **Save**.
4. Chờ 1-2 phút, bạn sẽ nhận được đường link web tĩnh dạng `https://<your-username>.github.io/love-anniversary/` để gửi cho người ấy!
